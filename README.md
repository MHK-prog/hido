# hido

برنامهٔ تمرینی موبایل با دو صفحهٔ جدا:

- «تعریف حرکت»: حرکت تکی بساز و ماهیچه‌هایش را روی نقشه انتخاب کن، یا یک حرکت ترکیبی بساز و حرکت‌های تکی را به ترتیب داخل سوپرست بچین.
- در سوپرست، برای هر حرکت تکرار یا زمان و وزنه را جدا تنظیم کن. تعداد ست‌های سوپرست (هر ست یک دور کامل)، استراحت بین حرکت‌های هر دور و استراحت بین ست‌ها برای کل سوپرست تنظیم می‌شود.
- «نوشتن برنامه»: حرکت تکی یا سوپرست تعریف‌شده را اضافه کن، ترتیب بلوک‌ها را بچین و برای حرکت تکی تعداد ست، تکرار/زمان، وزنه و استراحت بین ست‌ها را مشخص کن.
- استراحت بین بلوک‌های برنامه جدا از استراحت‌های داخل سوپرست تنظیم می‌شود.

## اجرا

در پوشهٔ پروژه این دستور را اجرا کن:

    python -m http.server 8000

در مرورگر برو به http://localhost:8000. برای انتخاب ماهیچه روی شکل در Android، برنامه باید از نشانی HTTPS باز شود.

کتابخانهٔ حرکت‌ها و برنامه در حافظهٔ محلی همان مرورگر ذخیره می‌شوند. حرکت‌ها و سوپرست‌های ذخیره‌شدهٔ نسخهٔ قبلی هنگام بازشدن برنامه حفظ و به ساختار فعلی منتقل می‌شوند.
