# hido

این مخزن دو برنامهٔ موبایل‌پسند دارد. `index.html` یک صفحهٔ ورودی کاملاً مستقل با دو لینک است؛ به فایل‌های برنامه یا کش آفلاین وابستگی ندارد و هنگام جداشدن دو سایت می‌توان آن را حذف کرد.

- **hido-co**: دو فهرست اصلی دارد: `programs.html` برای برنامه‌ها و `exercises.html` برای حرکت‌ها. افزودن برنامه در `program-editor.html` و افزودن/ویرایش حرکت در `exercise-editor.html` انجام می‌شود. مربی برای هر برنامه یک فایل JSON می‌گیرد و آن را برای ورزشکار می‌فرستد.
- **hido-show** (`hido-show.html`): ورزشکار فایل JSON مربی را باز می‌کند و برنامه، ست‌ها، تکرارها، وزنه‌ها و استراحت‌ها را می‌بیند. این صفحه برای نمایش است و برنامه را ویرایش نمی‌کند.

## روش استفاده

۱. مربی حرکت‌ها را در فهرست حرکت‌ها تعریف می‌کند، از فهرست برنامه‌ها برنامه می‌سازد و دکمهٔ «دریافت JSON» را می‌زند.
۲. ورزشکار فایل JSON را دریافت می‌کند، hido-show را یک‌بار با اینترنت باز می‌کند و فایل را انتخاب می‌کند.
۳. پس از بازشدن برنامه، hido-show آن را در همان مرورگر نگه می‌دارد تا آفلاین هم دیده شود. فایل JSON را هم برای پشتیبان‌گیری نگه دارید.

خروجی HTML آفلاین نیز در صفحهٔ ویرایش برنامه موجود است.

## استفادهٔ آفلاین

هر برنامه را دست‌کم یک‌بار با اینترنت و از نشانی HTTPS باز کنید تا Service Worker صفحه‌ها، قلم وزیرمتن و فایل‌های لازم را ذخیره کند. سپس هر دو برنامه در همان مرورگر بدون اینترنت در دسترس هستند. hido-co داده‌های مربی را در حافظهٔ همان مرورگر نگه می‌دارد؛ hido-show نیز آخرین فایل JSON بازشده را برای نمایش آفلاین ذخیره می‌کند. پاک‌کردن داده‌های مرورگر این اطلاعات را حذف می‌کند.

برای انتشار نسخهٔ تازه، مقدار `APP_VERSION` در `sw.js` را افزایش دهید. Service Worker کش تازه را می‌سازد و پس از فعال‌شدن، کش قدیمی را پاک می‌کند.

## اجرای محلی

در پوشهٔ پروژه این دستور را اجرا کنید:

    python -m http.server 8000

سپس `http://localhost:8000/programs.html` را برای فهرست مربی یا `http://localhost:8000/hido-show.html` را برای ورزشکار باز کنید. دکمه‌های `index.html` به آدرس‌های زندهٔ GitHub Pages می‌روند. Service Worker روی localhost هم کار می‌کند.
